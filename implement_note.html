4. Logic Thay Đổi & Điểm Nổi Bật

  • Layered Architecture & Separation of Concerns: Tách biệt hoàn toàn Controller (HTTP handling) → Service (Business Logic) → Repository (Data Access) → Entity/DTO Mappers.
  • Spring Security + Stateless JWT: Token-based authentication với Access Token (1 ngày) và Refresh Token rotation (7 ngày) lưu trong database.
  • Reader Engine: 3 giao diện đọc (Cream, Sepia, Night), tùy biến font/size/line-height/margin, auto-sync scroll vị trí đọc, mở khóa chương VIP bằng coins.
  • Swagger/OpenAPI 3.0: Tự động tạo tài liệu API tương tác tại http://localhost:8080/swagger-ui.html.

7. Cách Kiểm Thử (Testing Guide)

  1. Build Backend bằng Gradle Wrapper: 
    cd backend && gradlew.bat build
  2. Chạy Backend bằng Gradle Wrapper: 
    cd backend && gradlew.bat bootRun
    Truy cập Swagger UI: http://localhost:8080/swagger-ui.html
  3. Chạy Unit Tests cho Mobile: 
    cd mobile && flutter test
  4. Chạy Ứng Dụng Flutter Mobile: 
    cd mobile && flutter run
